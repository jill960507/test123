# 山餃線上訂單 × Google 試算表

網站結帳時，訂單會送到 Google Apps Script（GAS），寫進你的 Google 試算表，並寄通知信給你。

```
顧客在網站按「送出訂單」
   → GAS 網頁應用程式（Code.gs）
       ・依「菜單」工作表重新計算金額（顧客改不了價格）
       ・產生訂單編號 SJ-日期-流水號
       ・寫入「訂單」「訂單明細」
       ・寄新訂單通知信
   → 網站顯示訂單編號與總金額
```

## 一、第一次安裝（約 10 分鐘）

1. **建立試算表**：到 Google 雲端硬碟新增一份 Google 試算表，例如命名為「山餃訂單」。
2. **開啟 Apps Script**：在試算表上方選單點「擴充功能 → Apps Script」。
3. **貼上程式**
   - 把編輯器裡預設的 `Code.gs` 內容全部刪掉，貼上這個資料夾的 [`Code.gs`](Code.gs)。
   - 左側齒輪「專案設定」→ 勾選「在編輯器中顯示『appsscript.json』資訊清單檔案」。
   - 回到編輯器，打開 `appsscript.json`，用這個資料夾的 [`appsscript.json`](appsscript.json) 整份取代。
   - 按儲存（磁碟圖示）。
4. **初始化工作表**
   - 編輯器上方的函式選單選 `setup`，按「執行」。
   - 第一次會要求授權：選你的 Google 帳號。如果看到「Google 尚未驗證這個應用程式」，點「進階 → 前往（不安全）」。這是你自己的程式，所以會這樣顯示。
   - 完成後試算表會多出「訂單」「訂單明細」「菜單」「設定」「每日摘要」5 個工作表。
5. **部署成網頁應用程式**
   - 編輯器右上角「部署 → 新增部署作業」。
   - 類型選「網頁應用程式」。
   - 「執行身分」選「我」，「誰可以存取」選「所有人」。
   - 按「部署」，複製「網頁應用程式網址」，結尾是 `/exec`。
6. **接上網站**：把這個網址給 Claude，或自己貼到 `index.html` 裡的這一行：
   ```js
   const ORDER_API_URL = '';
   ```
   沒填網址時，網站會維持「模擬結帳」，不會送出任何資料。

## 二、日常使用

| 想做的事 | 怎麼做 |
| --- | --- |
| 處理訂單 | 在「訂單」工作表把「狀態」改成 製作中 → 可取餐 → 已完成（或已取消）。改狀態時會自動記錄「狀態更新時間」，並依狀態上色。 |
| 調整價格、下架品項 | 改「菜單」工作表的「價格」，或取消勾選「上架」。⚠️ 網站上顯示的價格寫在 `index.html`，要一起改，否則顧客看到的金額會和最後的總金額不同。 |
| 暫停接單（店休、備料不足） | 「設定」→「接單中」改成「否」。顧客送出時會看到「目前暫停線上接單」。 |
| 宅配運費 | 「設定」→ 填「宅配運費」和「免運門檻」。 |
| 通知信 | 「設定」→「通知信箱」，多個信箱用逗號分隔。可以用選單「山餃訂單 → 寄送測試通知信」試寄。 |
| 營業摘要 | 選單「山餃訂單 → 產生今日營業摘要」；或選「開啟每晚自動報表（21:00）」，每晚自動寫入「每日摘要」並寄信給「每日報表信箱」。 |

試算表重新整理後，上方會出現「山餃訂單」選單。

## 三、更新程式後要重新部署

改了 `Code.gs` 之後，要到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」。這樣網址不變，網站不用改。

## 四、安全性與限制

- 網頁應用程式網址是公開的，任何人都能送資料進來。程式已經做了這些防護：
  - 金額一律依「菜單」工作表重新計算。
  - 檢查欄位格式和數量上限（每項最多 99 份）。
  - 擋掉公式注入，例如姓名填 `=...` 不會被當成公式執行。
  - 用隱藏欄位擋機器人。
  - 同一次結帳重送不會重複建單。
- 個資（姓名、電話、地址）只存在你的試算表裡，試算表請不要公開分享。
- 個人 Gmail 帳號每天大約可以寄 100 封通知信，超過的話訂單仍會寫入，只是不會寄信。
- 這套流程不包含線上付款，付款在取餐或收貨時進行。
